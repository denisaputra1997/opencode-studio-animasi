# Konvensi Proyek

## Penamaan entitas

- Istilah **"manager"** selalu merujuk ke **masteragent**.
- Gunakan nama **masteragent** (bukan "manager") di semua tempat: kode, UI/label, nama event, `agent_id`, `role`, dan dokumentasi.
- Aturan ini berlaku sampai ada pernyataan lain dari user.

## Menjawab pertanyaan

- Jika user hanya **bertanya**, cukup jawab pertanyaannya. Jangan melakukan eksekusi/aksi apa pun (jangan edit file, jalankan perintah, atau mengubah sistem) kecuali user memintanya secara eksplisit.
